# 區域網路 / IP 連線對戰（網頁版）

## 開始遊玩

1. 房主電腦安裝 Node.js 22 以上。在包含 `package.json` 的專案根目錄執行 `npm install`，之後每次遊玩執行 `npm start` 即可。使用 pnpm 的開發者可執行 `pnpm install --frozen-lockfile` 使用已鎖定套件。
2. 房主開啟 `http://localhost:8787`，展開「區域網路 / IP 連線對戰」，按「建立房間（玩家一）」。
3. 主機啟動時會列出區域網路位址，例如 `http://192.168.1.20:8787`。另一位玩家連上相同 Wi-Fi，直接開啟該網址並按「加入此主機（玩家二）」，或在遊戲的 IP 欄輸入 `192.168.1.20:8787` 按「輸入 IP 加入」。後者會前往主機頁面並自動加入。
4. 房主選擇玩家一的顏色。雙方按「我準備好了」，房主按棋盤上的「房主開始對戰」。房主換色會取消雙方準備。
5. 每台裝置使用方向鍵或 WASD 操作自己的方塊，Enter / Space 直接落定；觸控只開放自己的面板。

每台主機只有一間雙人房。建立房間者是玩家一，加入者是玩家二；若房間已滿會顯示錯誤。可取消準備或離開房間，返回同機模式。

## 暫停、再戰與斷線

- 任一玩家可暫停 / 繼續；切換分頁或視窗會同步暫停雙方。
- 房主可按「新對局」，或在結算後按「再戰 / 重新準備」。雙方需重新按準備才能開局。
- 大廳中玩家二離開會立刻讓出座位，可換人加入；房主離開會關閉房間並通知另一位玩家。
- 對局進行中（含暫停）若 WebSocket 中斷，主機不會立刻終止該局：會暫停並保留棋盤、雙方當前方塊／下個方塊、分數與經過時間，進入最多 60 秒的重連視窗（`server/index.cjs` 的 `RECONNECT_MS`）。留下的玩家會看到「對方斷線，等待重連中」與倒計時。
- 建立／加入房間時主機會發放 `sessionToken`，瀏覽器存在 `sessionStorage`。斷線後客戶端以指數退避自動重連，憑 token 認領原座位（不用 IP 識別）。成功後主機下發完整狀態快照，雙方解除暫停繼續。逾時未歸則判留下的玩家獲勝，回到房間大廳。錯誤或缺失的 token 無法搶佔座位。
- 網路中斷透過心跳檢查偵測，通常約 5–15 秒內開始等待重連；失聯期間不會在瀏覽器自行推進棋盤。背景分頁的提示可能因瀏覽器節流而延後。重新整理頁面會嘗試以同一分頁的憑證恢復對局。按「離開連線」則立刻退出，不進入重連等待。
- 房主保持 `npm start` 的終端機開啟；按 Ctrl+C 關閉伺服器。

## 位址及連線問題

- **只有自己能連：** 朋友需用房主的區域網路 IP，不能使用 `localhost` 或 `127.0.0.1`。若電腦有 VPN／多張網卡，選擇與朋友相同網段的位址。
- **無法連線：** 確認主機正在執行、IP／連接埠正確、作業系統防火牆允許 Node.js 的 TCP 8787 連線。訪客 Wi-Fi 或 AP 隔離可能禁止裝置互連。
- **連接埠被占用：** macOS／Linux 可用 `PORT=9000 npm start`；Windows PowerShell 使用 `$env:PORT=9000; npm start`。朋友的位址也需改為 `主機IP:9000`。
- **GitHub Pages 或直接開啟 HTML：** 同機模式可直接玩。連線需前往主機提供的 HTTP 頁面；在 Pages 的 IP 欄輸入主機位址即可前往。若瀏覽器詢問區域網路存取權限，允許後再試。
- **不同網路：** 請先透過可互通的私人 VPN 連至同一網路，再輸入可達的主機位址。本版本沒有公網中繼、NAT 穿透、帳號驗證或 LAN 自動搜尋；預設供可信任的區域網路使用。

## 開發與驗證

```sh
npm install
npm test
```

`server/index.cjs` 使用 [ws 官方 WebSocket 實作](https://github.com/websockets/ws)。伺服器每 50ms 更新遊戲；落定、勝負與房間事件會廣播壓縮後的完整快照（棋盤編成 200 字元字串，約 626 B，較二維陣列全量約 865 B 少 28%），平時只送較小的 `tick`（經過時間與方塊位置，約 249 B，每 200ms 或方塊移動時）。收到操作時立即同步。客戶端僅提交自己的動作，玩家身分由連線決定；棋盤、隨機方塊、勝負及遊戲時間由伺服器計算。軟降按住狀態會定期更新並在超時後清除。重連時仍下發完整快照，畫面就地套用、不重建棋盤 DOM。

測試涵蓋核心規則、IP 解析、HTTP 資源限制、加入與滿房、雙方準備、換色、操作歸屬、狀態同步、暫停／再戰、大廳離席、對局斷線重連（狀態保留、token 恢復、逾時判負、憑證防搶座）與異常封包。Unity 與 Codea/Lua 版本尚未加入此連線協定，無法與網頁版互連。
