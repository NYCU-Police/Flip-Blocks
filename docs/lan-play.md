# 線上對戰（網頁版）

這份說明寫**玩家怎麼玩**與**協定細節**。怎麼啟動主機見根目錄 [README 的「自架主機」](../README.md#自架主機)；伺服器部署見 [拉取式部署說明](deploy.md)。同機與 AI 不必走這份流程。

## 開始遊玩

1. 用瀏覽器開啟已部署的遊戲網址，或自架主機提供的頁面。選「線上對戰」。
2. 輸入 2–12 字暱稱（會記住）。按「建立房間」，畫面會以大字顯示 6 位房間代碼（大寫字母與數字，不含易混淆的 0/O/1/I）。
3. 把代碼或「分享連結」（`?room=代碼`）傳給朋友。朋友開啟**同一個網站**，輸入暱稱與房間代碼後按「加入房間」。帶 `?room=` 的連結只會預填代碼，不會自動連上。
4. 知道房間代碼者可按「以觀戰加入」：只收狀態、不能操作。房內會顯示觀戰人數與暱稱。
5. 房主選擇玩家一的顏色。雙方按「我準備好了」，房主再按「房主開始對戰」。房主換色會取消雙方準備。
6. 每台裝置用方向鍵或 WASD 操作自己的方塊，Enter / Space 直接落定；觸控只開放自己的面板。觀戰者沒有操作權。

一般遊玩會自動使用目前網頁的網址，不必填主機 IP。只有要連到別人電腦上的主機時，才需展開「進階：自架主機」。大廳可開啟匿名排行榜（勝場前 20，同暱稱累計）。同機與單人 AI 不必輸入暱稱，也不上傳排行榜。

## 暫停、再戰與斷線

- 對局玩家可暫停／繼續；切換分頁或視窗會同步暫停雙方。觀戰者不會送出暫停。
- 對局結束後，房主可按「新對局」或「再戰／重新準備」。進行中不能重開。雙方需重新按準備才能開局。
- 大廳中離開會立刻讓出自己的座位，房間代碼仍有效；其他人可用同一代碼入座。
- 對局進行中（含暫停）若連線中斷，該房間會暫停並保留棋盤，進入重連視窗。工作階段憑證綁定房間代碼，重連回到原房間原座位。
- 雙方都離開（含重連逾時清座位）後，房間再保留一段時間供重連或再戰，然後回收。逾時未歸則判留下的玩家獲勝。
- 按「離開房間」立刻退出，不進入重連等待。對局中離開視為認輸，對手記入排行榜。

## 協定（WebSocket `/match`）

客戶端送出 JSON，身分由連線決定，不信任客戶端填的座位或棋盤。

| 方向 | `type` | 說明 |
| --- | --- | --- |
| C→S | `join` | `{ role: 'host'\|'guest'\|'spectate', name, code?, color? }`。建立房間時不要帶 `code`；加入／觀戰必填 6 位代碼。 |
| C→S | `reconnect` | `{ sessionToken, code }`，兩者都必須通過格式檢查。 |
| C→S | `ready` / `color` / `start` / `restart` / `pause` / `resume` / `input` / `leave` | 僅座位玩家有效；觀戰者的操作會被忽略。 |
| S→C | `joined` | `{ owner, sessionToken?, code, name, role }`。觀戰沒有 `sessionToken`。 |
| S→C | `state` | 壓縮棋盤快照，另含 `names`、`spectators`、`spectatorNames`、`code`、`reconnect`。 |
| S→C | `tick` | 進行中的較小更新，玩家與觀戰者都收得到。 |
| S→C | `reconnect-waiting` / `reconnected` / `reconnect-timeout` | 重連狀態。 |
| S→C | `error` | 驗證失敗或無法加入等；隨後斷線。 |

暱稱去掉控制字元與首尾空白後須為 2–12 字；房間代碼須符合字元集。非法或過長的訊息會被拒絕，原因是固定短字串，不會回顯使用者輸入。`GET /leaderboard` 只回 `{ rankings: [{ name, wins }] }`，不含憑證或內部狀態；頁面以 `textContent` 顯示暱稱。排行榜由伺服器在連線對局結算時寫入，同一房間同一局只記一次。

限額、訪客 IP（`TRUST_PROXY`）與資料目錄見 [`.env.example`](../.env.example) 與 [部署說明](deploy.md)。

## 連線問題

- **找不到房間：** 確認代碼 6 位、網址與朋友相同，且房間尚未回收。
- **無法建立房間：** 請稍後再試；可能暫時達到主機或該位址的上限。
- **只有自己能連（自架主機）：** 朋友不能使用 `localhost`。請用與朋友相同網段的主機位址，並確認防火牆允許遊戲連接埠。訪客 Wi-Fi 或 AP 隔離可能禁止裝置互連。
- **GitHub Pages 或直接開啟 HTML：** 同機／AI 可直接玩。線上對戰需前往連線主機提供的頁面，見 [README](../README.md#自架主機)。
- **不同網路：** 請先讓雙方能連到同一台主機（例如已部署的公開網站）。本專案沒有另外的公網中繼或 LAN 自動搜尋。

## 開發與驗證

```sh
npm install
npm test
```

`server/index.cjs` 使用 [ws](https://github.com/websockets/ws) 與 [better-sqlite3](https://github.com/WiseLibs/better-sqlite3)。伺服器定期更新各房間；落定、勝負與房間事件廣播壓縮快照，平時送較小的 `tick`。測試涵蓋多房間隔離、觀戰、排行榜去重、每 IP 上限與速率限制，以及既有的重連與規則測試。
